architecture
├─ synchronization
│  ├─ sync_k2 pairs position and velocity; integrate velocity without acceleration
│  ├─ sample age advances received position by velocity × age, capped by a .25s horizon
│  ├─ owners are tracked by entity UID; owner influence is configurable
│  ├─ correction: alpha = 1 - exp(-k*W*dt/(1 + L + W)), default k=8/s
│  ├─ sync_b is persistent state with hysteresis, not one-shot event delivery
│  └─ transport is external; test-only loopback uses a shared monotonic clock
├─ proposed credibility evolution
│  ├─ per desync: disc = c01(disc + sev); severity already incorporates packet interval
│  ├─ per update: disc = c01(disc - .05*dt)
│  ├─ per update: cred = c01(cred + (1 - cred - disc*disc)*.001*dt)
│  └─ packet-independent discrepancies such as ammo still need a severity rule
└─ current limitations: no restart epochs, schema negotiation or authenticated transport

Client database paths
├─ --db-dir selects the directory; default and make run use build/client/db
├─ each automated terminal client uses its own $tmpdir/A/testclientN
├─ interactive multi clients use build/multi/client1/db and client2/db
└─ the client loads trust data on startup and saves on clean exit; policy integration remains pending

current code
├─ src/p2p.nim uses uint64 peer IDs and external authenticated transport hooks
│  └─ peer ping and its limit use Milliseconds; sample age uses Seconds
├─ src/sync.nim reconciles marked entity fields and tracks ownership
├─ src/client.nim owns terminal initialization, drawing, controls and debug header
└─ tests/socket_gateway.nim is a test-only UDP relay, not an identity gateway

Trust persistence
├─ toml_serialization reads through a file input stream and writes TOML 1.0; IDs are normalized and validated
└─ trust_witnessed.toml persists both witnessed credibility and discredit; legacy trust-only files remain readable

synchronization details
├─ each kinetic record pairs position and velocity; no acceleration or intent prediction
├─ sender-row, transport and cached time contribute to sample age
├─ duplicates and reordered revisions do not refresh a report's age
├─ kinetic records expire at .25s; other records default to 2s
├─ expired motion does not imply stopping; local simulation retains velocity
├─ ownerBonus defaults to 0.3 credibility; finite owner preference does not prevent dilution
├─ sync_b has .6/.4 hysteresis and is not reliable event delivery
├─ records encode 128-bit entity ID, publisher revision and marked fields in little-endian order
├─ decoding walks the existing byte sequence with a cursor; StringStream would require converting it to a string
├─ malformed, nonfinite, negative-age, unknown and stale records are rejected
├─ expired reports retain watermarks; 64-bit transport keys are collision-checked
└─ report scanning and repeated decoding remain a scaling limitation

Doot hash
└─ src/doot_hash.nim preserves the integer hash formulas with uint32 results

Doot map
├─ src/hmap.nim uses fixed-depth buckets with packed deletion
├─ get returns a Maybe for missing keys, including stored nil; [] raises KeyError
├─ padding reserves room during expansion
└─ Monte Carlo allocation grows until padding fits, with no imposed growth cap

Owner influence measurements (deterministic simulation)
├─ make owner_measurements: 25ms ticks, seed 123, owner bonus 0.3
├─ fixture uses raw peer trust without the credibility/reliability position policy
├─ matrix: 2, 4, 8 and 16 peers; 0, 40, 80 and 160ms latency, half-latency jitter
│  └─ 25% loss except zero-latency case; one-time jump settles from 4.74 down to 0.37 at owner
├─ four peers: impulse settles near 2.61 cells without delay and 1.81 at 80ms
├─ holding the owner at 8: after 10s the owner is 7.94–8 across the matrix
├─ four peers with one held dissenting peer: owner near 7.52, other peers near 4.92
└─ these fixture outcomes show dilution; they are not authority guarantees
