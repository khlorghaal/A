build and inspection
├─ initialize deps/termbox2 and install Nimble, C, Clang and GLib runtime dependencies
├─ make builds; make check checks; make test runs tests; make run starts the game
├─ after changing termbox headers, rebuild Futhark imports with make NIMFLAGS=-d:opirRebuild
├─ make multi_agentvm runs four PTY clients through a test-only simulated network
│  ├─ tests/sim_socket.nim schedules delay, jitter and loss
│  └─ raw terminal output and test state are under build/multi
└─ llm/terminal/vterm.py provides PTY key, mouse, resize and capture commands
   └─ captures are reconstructions; inspect raw terminal output for shaping issues

Build targets
├─ make run starts the client; make multi opens an interactive tmux pair
├─ make test runs automated game, sync and trust checks without tmux
├─ make check builds the client and checks the network/sync modules
├─ make multi_agentvm runs deterministic network checks and four real PTYs
├─ NIMFLAGS applies to every compilation target
└─ game binaries depend on src/*.nim; gateway is currently only a test relay
