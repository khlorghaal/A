build and inspection
├─ blastd submodule at deps/blastd; A records blastd commit
│  └─ provisional ../blastd URL: update when blastd remote exists
├─ initialize deps/termbox2 and install Nimble dependencies, C, Clang and GLib runtime dependencies
├─ make / make run starts the client; make build/A builds it without running
│  └─ --db-dir DIRECTORY selects the client trust database; default is build/client/db
├─ make test runs game, sync, hash/map and trust checks without tmux
│  └─ gateway TLS checks require OpenSSL runtime and openssl command; temporary certs
├─ make check builds the client and checks the network/sync modules
├─ make multi opens an interactive two-client tmux session
├─ make build/test/colors builds the interactive true-color sample
├─ rebuild Futhark imports with make -B build/A fgs=-d:opirRebuild
├─ make multi_agentvm runs four PTY clients through a test-only simulated network
│  ├─ tests/sim_socket.nim schedules delay, jitter and loss
│  └─ raw terminal output and test state are under build/multi
└─ llm/terminal/vterm.py provides PTY key, mouse, resize and capture commands
   └─ captures are reconstructions; inspect raw terminal output for shaping issues

Build behavior
├─ make test reruns blastd checks when source/test/package/Makefile timestamps advance
│  └─ build/blastd-testpass records success; delete stamp after compiler/flag changes
├─ fgs supplies extra Nim flags; Termux adds Futhark include paths and opirRebuild
├─ game binaries depend on src/*.nim
└─ build/gateway/relay is the test relay; the identity gateway is still pending

Owner measurements
