# Project skills

These project-local skills combine the supplied Chat/Projects archive with the
repo's task workflow. Run project commands from the repository root. AGENTS.md
points here; no cloud skill sources are modified by this local synchronization.

- `do`: autonomous authorized work, commits, visual review, tests and handoffs; `burn` strengthens continuation.
- `cman`: compressed responses, with manual and topic-based activation.
- `paste`: a single copyable command unless further context is essential.
- `todo`: active/deferred queue semantics and removal of verified completed items.
- `visual-annealing`: repeated narrow and broad inspection of rendered code.
- `pqt`: pause execution until the user explicitly authorizes resumption.
- `tree-notes`: compact, durable hierarchical working notes.
- `session-handoff`: decisions, Git state, actual test outcomes and next actions.
- `contemplate`: a brief relevant tangent when invited.
- `vacation`: an explicitly requested detour, including `do`'s brief checkpoint.

Merge policy: retain complementary features and repo-only skills. Explicit user
constraints take precedence. `do`'s explicit vacation invocation reconciles its
post-commit checkpoint with the archive's requirement that vacation be requested.
The archive's `visual-annealing` already matched the repo and was kept unchanged.
